# Aye Chan's Resume Portfolio Website

Welcome to my resume portfolio! This is a modern, responsive web application built to showcase my technical background, professional experiences, certifications, and projects.

## 🌐 Live Site

Visit: [https://aye-chan.net](https://aye-chan.net)

## 📄 About

This project was originally inspired by the [Cloud Resume Challenge](https://cloudresumechallenge.dev/) by Forrest Brazeal. It demonstrates my full-stack and cloud development skills using modern technologies and AWS services.

## 💻 Features

- ✅ **Responsive Design** using HTML5, CSS3, and JavaScript
- 📈 **Visitor Counter** powered by:
  - AWS Lambda (Python)
  - API Gateway
  - DynamoDB
- 📬 **Contact Form** that sends emails using:
  - AWS Lambda (Node.js)
  - API Gateway
  - AWS SES
- ☁️ **Deployed Serverlessly** via:
  - Amazon S3 (static site hosting)
  - CloudFront (global content delivery)
  - Route 53 (DNS + HTTPS)
- 🔁 **CI/CD** with GitHub Actions: automatic deployment to S3 on every push

## 🧰 Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Cloud Services**: AWS S3, CloudFront, Route 53, Lambda, DynamoDB, SES, API Gateway
- **DevOps**: GitHub Actions
- **Other Tools**: Font Awesome, Google Fonts
